## Description
The **Random Quote Generator** is a React-based application that fetches random quotes from the DummyJSON API. Users can view a random quote and request another one at the click of a button. This application serves as a fun way to get inspired and motivate users with new quotes.

## Features
- Fetches random quotes from the DummyJSON API.
- Displays the quote and its author.
- Button to fetch a new random quote.
- Simple and intuitive user interface.

## Technologies Used
- **React:** JavaScript library for building user interfaces.
- **Axios:** Promise-based HTTP client for making requests to the API.
- **CSS:** For styling the application.

## Installation
To set up the project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/random-quote-generator.git

2. **Navigate to the project directory:**
    cd random-quote-generator

3. **cd random-quote-generator:**
    npm install / yarn

4. **Start the development server:**
    npm run dev

5. **Open your browser and go to http://localhost:5173 / whatever your port no.**

## Usage
- Once the application is running, you will see a random quote displayed on the screen.
- To get another quote, simply click the "Get Another Quote" button.
- Enjoy and share your favorite quotes!

## API
- The application uses the following API to fetch quotes:
**API Endpoint:** https://dummyjson.com/quotes?limit=0
